# Biểu tượng Extension

Kho không bao gồm các file biểu tượng `.png` để tránh lưu trữ nhị phân. Hãy thêm ba biểu tượng với kích thước 16x16, 48x48 và 128x128 pixel theo tên sau khi build:

- `icon16.png`
- `icon48.png`
- `icon128.png`

Những file này sẽ được tham chiếu bởi `manifest.json` khi bạn tải extension ở chế độ developer.
